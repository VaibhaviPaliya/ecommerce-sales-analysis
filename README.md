**E-Commerce Sales & Customer Insights Analysis
A compact, end-to-end data analysis project in Python designed to evaluate synthetic e-commerce transaction data, uncover top revenue drivers, analyze monthly demand trends, and identify high-value customers.
---
📊 Project Overview
This project simulates and analyzes a dataset of 1,000 online retail transactions. By leveraging data manipulation and visualization libraries, it transforms raw sales logs into actionable business insights:
Revenue Distribution: Determining which product categories drive the most sales.
Temporal Trends: Tracking month-over-month revenue performance throughout the year.
Customer Segmentation: Identifying top customers based on lifetime spend.
---
🛠️ Tech Stack
Language: Python 3.8+
Data Manipulation: `pandas`, `numpy`
Data Visualization: `matplotlib`, `seaborn`
---
📈 Key Findings & Business Insights
Top Revenue Driver: Electronics dominate total sales, generating more than % of overall company revenue due to higher average unit prices.
Stable Demand: Apparel and Home & Kitchen maintain steady transaction volumes consistently across quarters.
Customer Concentration: The top 5 highest-value customers account for 16.6% of revenue, indicating strong targets for loyalty reward programs.
---

⚙️ How to Run Locally
1. Clone the Repository
```bash
git clone https://github.com/your-username/ecommerce-sales-analysis.git
cd ecommerce-sales-analysis
```
2. Install Dependencies
```bash
pip install -r requirements.txt
```
3. Run the Analysis Script
```bash
python analysis.py
```
